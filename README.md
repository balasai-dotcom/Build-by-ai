# Even or Odd Python Program

This beginner-friendly Python program checks whether a number is even or odd.

## How to run

1. Run the program:

   ```bash
   python main.py
   ```

2. Enter an integer when prompted.

3. The program prints `Even` if the number is divisible by 2. Otherwise, it prints `Odd`.

## Example

```text
Input: 8
Output: Even
```

The `%` operator finds the remainder after division. When `number % 2` is `0`, the number is even.
